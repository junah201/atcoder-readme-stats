## Usage

### V1

The v1 design was created by [@junah201](https://github.com/junah201).

using html

```html
<a href="https://atcoder.jp/users/your_handle" target="_blank">
	<img src="https://atcoder.junah.dev/v1/generate_badge?name=your_handle" />
</a>
```

or using markdown

```markdown
[![Atcoder](https://atcoder.junah.dev/v1/generate_badge?name=your_handle)](https://atcoder.jp/users/your_handle)
```

### V4

The v4 design stamps your Kyu/Dan as a Japanese 段位 seal (e.g. 五級, 初段, 極伝), with the layout inspired by [mazassumnida](https://github.com/mazassumnida/mazassumnida) v2. The progress bar shows how far your highest rating is from the next promotion.

using html

```html
<a href="https://atcoder.jp/users/your_handle" target="_blank">
	<img src="https://atcoder.junah.dev/v4/generate_badge?name=your_handle" />
</a>
```

or using markdown

```markdown
[![Atcoder](https://atcoder.junah.dev/v4/generate_badge?name=your_handle)](https://atcoder.jp/users/your_handle)
```
